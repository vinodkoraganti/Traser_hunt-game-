# 🏴‍☠️ Treasure Hunt Game

## 📌 Project Description
Treasure Hunt Game is an interactive game where players search for hidden treasures by exploring different locations and solving clues. The game challenges players' logical thinking, problem-solving abilities, and decision-making skills.

## 🎯 Objectives
- Develop logical thinking and problem-solving skills.
- Create an engaging interactive gaming experience.
- Understand programming concepts through practical implementation.
- Improve decision-making through game challenges.

## ✨ Features
- Interactive gameplay.
- Treasure searching challenges.
- Clue-based exploration.
- Player-friendly interface.
- Winning and losing conditions.
